INF - DEVICE MATCH AND INSTALL SECTION
======================================

Status: DONE

1. PURPOSE

1.1 The INF matches the GT 1030 to the driver.
1.2 Windows reads the INF during installation and during device start.
1.3 Without the INF entry, the installer refuses the card.

2. PIECE DESCRIPTION

2.1 The display INF is templates/package/Display.Driver/nv4_dispi.inf.
2.2 Each supported card has one line in the device section.
2.3 Each line maps a hardware ID to an install section.
2.4 The install section selects the driver files and settings.

3. CHANGE IN THIS WORK

3.1 This work adds one device line for the GT 1030.
3.2 The hardware ID is PCI\VEN_10DE&DEV_1D01.
3.3 The install section is Section012.
3.4 Section012 is the section used by the other desktop Pascal cards.
3.5 The display name is "NVIDIA GeForce GT 1030".

4. BUILD EFFECT

4.1 The builder checks the SHA-256 of each template.
4.2 A change to the INF changes its SHA-256 and its size.
4.3 This work updates both values in patches.json.

5. VERIFIED RESULT

5.1 The installer accepts the card.
5.2 Windows PnP matches the card to Section012.
5.3 The driver loads.
5.4 The card then reports Code 10 for a later reason.
5.5 This piece is complete. The failure is not in this piece.

6.2 desktop-gpus.json for the full device list.
