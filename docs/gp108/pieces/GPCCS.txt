GPCCS - GPC COMMAND PROCESSOR FIRMWARE
======================================

Status: PARTIAL

1. PURPOSE

1.1 GPCCS is a processor inside the graphics engine.
1.2 GPCCS runs signed firmware.
1.3 GPCCS works with FECS during graphics startup.

2. RESOURCE SET

2.1 The GPCCS firmware is part of the graphics bundle. See GR.txt.
2.2 The GPCCS set has an instruction image and a data image.
2.3 The GPCCS set has a separate signature resource.

3. DONOR RESOURCES

3.1 The GP108 GPCCS instruction size is 12547 bytes.
3.2 The GP108 GPCCS signature is at donor descriptor 0xB9C5F8. Its size
    is 192 bytes.
3.3 The GP108 GPCCS data image size is 2100 bytes. This size matches
    GP107, but the bytes differ.

4. CONSTRUCTOR AND SIGNATURE FIELD

4.1 The GPCCS constructor is slot 25 in the chip table.
4.2 The donor GP108 constructor writes the signature getter to field
    +0x20.
4.3 The donor GP108 constructor clears field +0x24.
4.4 The GP107 constructor uses field +0x28.
4.5 This field difference is mirrored in the prototype.

5. OPEN POINTS

5.1 The XP consumer must read the same field that the prototype writes.
5.2 Confirm the XP signature field before the next hardware test.
5.3 Keep the GPCCS image and its signature from the same release.

6. REFERENCES

6.1 DECOMP_NOTES.md, slot 25 row.
6.2 linux-firmware nvidia/gp108 for the reference file set.
