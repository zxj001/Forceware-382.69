CAPABILITY-SLOTS - REMAINING GP108 TABLE DIFFERENCES
====================================================

Status: OPEN

1. PURPOSE

1.1 The GP108 chip table differs from the GP107 table in 12 slots.
1.2 Three slots carry firmware. See GR.txt, FECS.txt, and GPCCS.txt.
1.3 Nine slots carry other setup. This file covers those nine.

2. THE NINE SLOTS

   Slot  Subject                       Note
   4     Bus initialization            Drops a Quadro P400 quirk.
   5     Memory-subsystem registers    Same base as GP107; adds one
                                       method that writes 0x10402C
                                       and 0x104034.
   6     Capability bytes              Sets fields at +0x74.
   8     Capability bytes              Sets fields at +0x6F8 to +0x720.
   15    Per-config paths + bytes      Selects paths; sets +0x732 fields.
   27    Register and value lists      Two list getters.
   50    Constant and mask getters     Returns 4; returns 0x20000 on a mask.
   53    Capability bytes              Sets fields at +0x141.
   55    GP106 variant                 GP108 reverts to the GP106 version.

3. RISK NOTE

3.1 Slot 5 writes memory-subsystem registers.
3.2 Determine the purpose of those writes before you apply them.
3.3 Do not mirror slot 5 by copying values alone.

4. METHOD

4.1 Identify the engine and purpose of each slot.
4.2 Compare the donor behavior with the inherited XP behavior.
4.3 Keep inherited behavior where the comparison proves it is equivalent.
4.4 Map each required constant and callback to the XP structures.
4.5 Implement each real difference as a separate change.
4.6 Some capability fields depend on different private structure layouts.
    Confirm the XP layout before you copy an offset.

5. SEQUENCE

5.1 The static comparison can start now.
5.2 The runtime check depends on successful firmware startup. See ACR.txt.
