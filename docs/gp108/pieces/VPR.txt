2.2 The VPR set has a payload, a header, and signature records.

3.2 The VPR payload is byte-identical in the 382.33 donor.
3.3 The VPR header is byte-identical in the 382.33 donor.
3.4 The VPR signatures are byte-identical in the 382.33 donor.

4. RESULT

4.1 The VPR resources already match the donor.
4.2 This piece needs no change for GP108.
4.3 The VPR resources are not the cause of the current failure.
